# A Little Big History of Timekeeping

An essay written for the Big History course at the University of Amsterdam, tracing timekeeping from the first stars, through the biological clocks of life, to shared human time infrastructure and the Anthropocene, with the Patek Philippe Reference 2523 world-time wristwatch as a concrete example along the way.

**Read it here: [dariocodes.github.io/big_history](https://dariocodes.github.io/big_history/)**

- `index.html` is the published page.
- `final_paper.md` is the canonical text of the essay.
